# 0.5.4 需求与审核记录

## 需求绑定

| 用户指令或已确认约束 | 修改 | 验证方式 |
| --- | --- | --- |
| 透明界面“字体一定要清晰”，进一步明确“字体加粗加亮” | 正文和终端 600、标题/粗体 700，白色正文、提亮辅文、细暗边；终端 DIM 提高字形 alpha，保留 RGB 和用户字号 | 三主题真实 PTY 的普通/粗体/DIM/ANSI/256色/真彩色/反色及选区；文件编辑和 Markdown |
| 顶栏贴顶及左右两边 | 移除外边距和圆角，保留底部细边 | 总览、窄窗、放大项目的实际边界坐标 |
| 底栏贴底及左右两边 | 底栏提升为整个 app-shell 子元素，放大后也横跨侧栏；移除预览旧 28px 预留 | 总览、窄窗、侧栏、编辑/预览边界与底部间距 |
| 终端间距缩小、圆角减小 | 网格间距 15→8px，外壳圆角 22→14px，内部首尾圆角跟随为 13px | 计算样式、窄窗控制排列、实际截图及展开/拖动回归 |
| 呼吸灯“一亮一暗” | 同一 2s 缓进缓出周期，0/2s 暗、1s 亮，状态点与整圈边缘同步；悬停/输入聚焦时仍有明显低谷 | 三种交互下各 2.4s 原生采样，0/1/2s 截帧，灯边和圆点相位核对 |
| 既有：透明材质、输入不放大、完成提示不反复出现 | 不改玻璃透明度、终端会话和通知状态逻辑；新完成仍 3 次，旧空闲保持安静，减少动态效果继续关闭呼吸 | 玻璃像素 A/B、三主题、不透明回退、输入/展开、完成去重检查 |

## 审核意见与处理

| 审核意见 | 依据 | 最小修正 |
| --- | --- | --- |
| 底栏若仍在主工作区内，放大后左侧无法贴边 | 用户要求底栏贴左右两边 | 将底栏提升到整个应用布局，预览同步去掉旧底栏预留 |
| 只改前景不能提亮 xterm DIM，因为其颜色自带 0.5 alpha | 用户要求所有文字加亮 | 用相对颜色只提高字形 alpha，无过滤器、DOM 观察器或额外层 |
| 默认反色在选区内显示深字，蓝灰选区上不清楚 | 选中时文字也要可读 | 限定 xterm 6 默认反色 257 + 当前选区 decoration 类，排除块光标；检查清除选区后恢复 |
| 悬停/焦点的旧低谷过亮，导致近似常亮 | 用户明确“一亮一暗” | 分别降低普通/悬停/焦点低谷，周期改成对称 0→1→2 秒 |
| 新采样不能套用旧版本性能数字 | 如实记录验证结果 | 本轮独立记录 rAF 间隔，不等同 GPU 帧率；不把工作集当作显存 |
