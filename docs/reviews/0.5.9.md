# v0.5.9 — Git sidebar

## Request and scope

The expanded project should show Git status like VS Code. Replace the explorer's bottom Settings action with Git history; opening it collapses the file tree and shows committed and uncommitted work in that sidebar. Keep Settings available in the top bar. No staging, commit, checkout or fetch controls are introduced.

| Acceptance criterion | Change | Verification |
| --- | --- | --- |
| Replace sidebar Settings and collapse the explorer when opening Git | `ProjectExplorer.tsx` switches the existing sidebar; the tree stays mounted and preserves expanded folders | Packaged `test:git`: sidebar button, hidden tree, return to expanded folders, collapsed-sidebar entry |
| Distinguish committed and uncommitted work | `GitPanel.tsx` separates staged, worktree and conflict groups from paginated commit history and changed files | Real Git fixtures cover mixed staged/worktree changes, renames, deletions, conflicts, empty history, merge parents and pagination |
| Show readable history relationships and file status | Parent-based SVG graph, file badges and ancestor-directory indicators using existing themes | Packaged local/SSH screenshots; SVG preserves vertical continuity when lanes exceed the available width |
| Local and SSH status remain accurate | Bounded read-only Git commands, shared parsing, SSH worker operation; UTF-8 and NUL-delimited paths | Node and Python Git tests; real OpenSSH transport integration, detached HEAD, worktrees, subdirectories and branch tracking |
| Preserve terminal and file workflows | Existing file-opening guard; no session mutation; visible-sidebar polling only | Packaged `test:git`: session/draft preservation, unsaved navigation cancellation, auto-refresh, pause while collapsed; packaged navigation and themes/Markdown regressions |
| Avoid expensive repeat work | Coalesced reads, timeout/output limits, 15-second failure backoff; history reloads on HEAD/branch/page/manual refresh | Injected failure and request counters in isolated packaged GUI; index bytes unchanged after status reads |

## Corrections during verification

- `log.showSignature=true` polluted machine-readable history and parent output for signed commits. Both local and SSH runners explicitly disable signature display. Real signed-header fixture tests now pass on both implementations.
- The original narrow-window script resized a fullscreen window without verifying the viewport. It now exits fullscreen, waits for 900×620 and for history to load before checking and capturing the layout.
- Wide history graphs could shrink vertically under SVG's default aspect-ratio behavior. The main graph now uses the same non-uniform scaling as the expanded-detail continuation.
