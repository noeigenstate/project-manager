# 玻璃材质设计

Project Grid 的玻璃效果参考 [Apple 的材质设计说明](https://developer.apple.com/design/human-interface-guidelines/materials)，使用 Electron 中的 CSS 实现，不依赖 Apple 原生框架。

视觉主线是通透的控制层与稳定的阅读层，保留原有树影、蓝天、白云油画作为环境色来源。

- **工作区**：项目仍是可操作的网格方框。圆角与双层边缘高光表现厚度，柔和阴影表现层次；项目正文叠加暗色承托，保持终端文字与 ANSI 色彩清晰。
- **导航与控制**：紧凑顶部栏、搜索框、胶囊按钮与开关使用更通透的表面；正文不做扭曲或折射处理。
- **辅助界面**：弹窗、菜单和拖动提示浮在工作区上，使用更厚的材质与独立阴影。
- **状态灯**：参考用户提供的呼吸灯分镜，运行中与新完成提醒采用 2px 蓝→紫→粉→橙矢量边缘、四角高光和约 12px 的外侧柔光。一个装饰节点承载边缘，删除旧整卡阴影动画、反光覆盖层和左右短灯条。右上角圆点保留蓝色处理、粉色待查看、绿色完成的含义。
- **动态反馈**：边缘与圆点共用 2 秒缓进缓出周期，0 秒低亮、0.8 秒峰值、1.6 秒回落、2 秒进入下一周期。只动画装饰层的不透明度，不重绘整卡阴影或过滤终端文字。工作中持续呼吸；新的完成提醒只播放 3 次（约 6 秒），旧完成超过 9 秒的检测窗口不会被重新唤起。绿色完成保持常亮。焦点卡片高于悬停卡片，普通空闲卡片最弱。
- **清晰度**：项目名 14px，状态/分支/时间等信息 11–12px；窄卡片省略次要文字，保留状态点与完整悬停说明。正文承托加深，顶栏、侧栏和底栏同样抑制白云透入；终端保留用户字号和 ANSI 色彩，行距调整至 1.3。图片背景仍为原有 1672×941 油画，另外两个主题为 SVG；4K 截图验证的是界面在高 DPI 下的绘制，不能将原背景称为 4K 素材。
- **项目展开**：只有顶部标题栏和展开按钮响应普通单击放大；终端正文、输入区和底栏可在小窗口中直接操作。卡片从当前位置逐渐放大，约 720 毫秒内落位；返回时约 560 毫秒缩回网格。可见窗口保持正常绘制，隐藏到托盘或最小化后恢复渲染节流；动画验证不再额外添加测试专用的渲染开关。使用实际终端节点，保持会话和未发送输入；快速返回时从当前尺寸反向过渡。
- **系统偏好**：减少动态效果时关闭动画和过渡；减少透明度时主要表面改为实色。

材质令牌和状态样式位于 `src/glass.css`。视觉调整以终端、文件查看与多项目操作的可读性为前提，保留原来的布局密度。
