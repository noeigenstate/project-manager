# 玻璃材质设计

Project Grid 的玻璃效果参考 [Apple 的材质设计说明](https://developer.apple.com/design/human-interface-guidelines/materials)，使用 Electron 中的 CSS 实现，不依赖 Apple 原生框架。

视觉主线是通透的控制层与稳定的阅读层，保留原有树影、蓝天、白云油画作为环境色来源。

- **工作区**：项目仍是可操作的网格方框。圆角与双层边缘高光表现厚度，柔和阴影表现层次；项目正文叠加暗色承托，保持终端文字与 ANSI 色彩清晰。
- **导航与控制**：紧凑顶部栏、搜索框、胶囊按钮与开关使用更通透的表面；正文不做扭曲或折射处理。
- **辅助界面**：弹窗、菜单和拖动提示浮在工作区上，使用更厚的材质与独立阴影。
- **反馈**：按钮轻微按压回弹，菜单短促展开，拖动时目标方框亮边。红色等待提醒、绿色开发完成的含义保持一致。
- **项目展开**：点击卡片后从当前位置平滑放大，约 460 毫秒内减速落位；返回时约 380 毫秒缩回网格，其他项目淡入。使用实际终端节点，保持会话和未发送输入；原生窗口尺寸变化时重新计算落点，快速返回时从当前尺寸反向过渡。
- **系统偏好**：减少动态效果时关闭动画和过渡；减少透明度时主要表面改为实色。

材质令牌和状态样式位于 `src/glass.css`。视觉调整以终端、文件查看与多项目操作的可读性为前提，保留原来的布局密度。
